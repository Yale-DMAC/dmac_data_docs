# Request Types 
SCMS provides the following services: 
- Data Remediation: Updating or deleting of existing fields or records 
- Data Creation or Enhancement: Creation of new fields or records, or the Enhancement of existing ones. 
- Data transformation: migrations, mappings, data re-use 
- Reporting and data analysis 
- Tool and workflow support: automation and process improvement 
- ArchivesSpace support: product ownership, application and user management 
- General Support: Other requests 

## Data Remediation 
Data Remediation services consists of the bulk updating, altering, or deletion of existing fields or records in special collections metadata. 

**Examples**  
- Identify and delete expired restriction dates 
- Clean up controlled value lists in ArchivesSpace 
- Update preferred citation notes for Divinity after library name change 
- Delete archival object records for materials which have been reprocessed 
- Normalize local subject headings under a single version 

[See Requesting Data Remediation from SCMS for more information.](/data_remediation.md) 

## Data Creation or Enhancement 
Data Creation or Enhancement services includes the creation of new fields or records, or the enhancement of existing fields or records. 

**Examples** 
-  Add structured dates to ArchivesSpace records which previously only had free-text dates 
- Add SNAC identifiers to agent records 
- Add barcodes to location records 
- Create new top containers and add them to existing records 
- Add linked data to existing subject headings 

[See Requesting Data Creation or Enhancement from SCMS for more information.](/data_enhancement.md)

## Data transformation 
Data transformation services include data migrations and conversions, data re-use projects, and integrations with other systems. 

**Examples**  
- Migrate YNHH data from Access database and Word documents to ArchivesSpace 
- Develop mappings between ArchivesSpace and Lux 
- Convert Proquest-provided dissertation metadata to Elischolar and Voyager records 
- Reassociation of data between Find-It/Ladybird and ArchivesSpace 
- Integration of ArchivesSpace and Quicksearch 

[See Requesting Data Transformation from SCMS for more information.](/data_transformation.md)

## Reporting and data analysis 
Reporting and data analysis activities can stand on their own or be provided as part of another service such as data management and transformation. 

**Examples**  
- Report on Papyri records in order to facilitate migration to DCS, additional physical processing, and patron research 
- Report of University Archives materials stored at off-site storage 
- Report of all acquisitions in the last 5 years 
- Reporting to support Special Collections backlog project 
- Reports plugin: report of all materials in a given collection that are digitized and in Preservica and/or DCS 

[See Requesting Reports from SCMS for more information.](/reporting_analysis.md)

## Tool and workflow support 
Tool and workflow support services include creating, updating, or repairing tools, plugins, or workflows for special collections staff. 

**Examples** 
- Maintain Excel-to-EAD transformation tool 
- Workflow for automated processing of electronic dissertations 
- Copy order fulfillment process for previously digitized materials 
- Box and folder labeling process 
- Workflow support for Digital Accessioning Service 
- LSF barcode search tool 

[See Requesting Tool or Workflow Support from SCMS for more information.](/tool_support.md)

## ArchivesSpace Support 
ArchivesSpace Support services consist of resolving errors or issues related to ArchivesSpace or Archives at Yale. 

**Examples** 
- Granting repository permissions to staff 
- Assisting with ArchivesSpace account creation 
- Troubleshooting errors or glitches staff encounter 
- Updating Archives at Yale interface to include new repositories in the menus 
- Answering questions related to ArchivesSpace policies 
- Training Staff to use ArchivesSpace 

[See Requesting ArchivesSpace Support from SCMS for more information.](/aspace_suport.md)

## General Support 
General Support services are for any other request that does not neatly fit into a precious category. 

**Examples** 
- General Metadata Services staff training 
- Offering advice or consultations on projects 
- Questions about available services 
- Requests that may involve multiple service areas 

[See Requesting General Support from SCMS for more information.](/general_support.md)
