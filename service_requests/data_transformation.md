# Requesting Data Transformation from SCMS 

## Overview 

Our unit provides data transformation services for projects involving data migration, data conversion, data re-use, and system integrations. 

**Examples include:**
- Migrating data from an Access database and Word documents into ArchivesSpace 
- Reassociating data between Find-It/Ladybird and ArchivesSpace 
- Converting ProQuest-provided dissertation metadata into EliScholar and Alma records 
- Transforming metadata from one format into another 
- Integrating data between systems 

To ensure projects are completed as efficiently and accurately as possible, please provide as much detail as you can when submitting a request. 

Incomplete or unclear requests may require follow-up questions and can delay project timelines. 

## Before Submitting a Request 

Consider the following questions: 
- Where is the data currently stored or what format is it currently in? 
- Where does the data need to go? 
- What data should be included in the project? 
- Are there any records or data elements that should be excluded? 
- How many records are estimated to be affected? 
- Are there existing mappings, crosswalks, or documentation available? 
- What should the final result look like? 
- Do you have sample records, files, or screenshots that illustrate the project? Providing examples is often the fastest way to help us understand your request. 

## Helpful Examples 

**Instead of:**
> We need to move some legacy data into ArchivesSpace. 

**Consider:**
> We need to migrate collection metadata currently stored in an Access database into ArchivesSpace resource and archival object records. Sample records and field documentation are attached. Existing identifiers must be preserved, and records with a status of "obsolete" should not be migrated. 

## What Happens Next 

After reviewing your request, we may: 
- Clarify project requirements 
- Review sample data and documentation 
- Identify potential data quality issues or transformation challenges 
- Discuss data mappings and transformation rules
