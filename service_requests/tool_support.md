# Requesting Tool or Workflow Support From SCMS 

## Overview 

Our unit provides support for tool development, tool enhancements, workflow improvements, automation, and process optimization. 

**Examples include:**
- Creating user-run reports in ArchivesSpace or Alma Analytics 
- Developing scripts or automation tools 
- Enhancing existing tools 
- Resolving issues with existing tools 
- Designing workflows for automated processing 
- Improving manual or repetitive processes 

To ensure requests are completed as efficiently as possible, please provide as much detail as you can when submitting a request. 

Incomplete or unclear requests may require follow-up questions and can delay project timelines. 

## Before Submitting a Request 

Consider the following questions: 
- What task or workflow are you trying to accomplish? 
- What problem are you currently experiencing? 
- What system, tool, or process is involved? 
- What is the current workflow? 
- What would the desired workflow look like? 
- Is this a request for a new tool, an enhancement, an issue, or a workflow improvement? 
- Who will use the tool or workflow? 
- Do you have examples, screenshots, or documentation that illustrate the request? Providing examples is often the fastest way to help us understand your request. 

## Helpful Examples 

**Instead of:**
>We want to automate dissertation processing. 

**Consider:**
>We would like to reduce manual processing of electronic dissertations. Currently, staff download metadata files, manually transform the data, and load records into multiple systems. We would like an automated workflow that validates the files, transforms the metadata, and creates records in the appropriate systems. Sample files and workflow documentation are attached. 

## What Happens Next 

After reviewing your request, we may: 
- Clarify requirements and workflow details 
- Review existing tools, documentation, and processes 
- Identify opportunities for automation or process improvements 
- Discuss implementation options and constraints
