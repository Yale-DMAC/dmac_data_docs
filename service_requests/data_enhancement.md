# Requesting Data Creation or Enhancement From SCMS 

## Overview 

Our unit provides data creation and enhancement services for projects involving the bulk creation of new records, the addition of new data to existing records, or the enhancement of existing records with information not currently present. 

**Examples include:**
- Adding SNAC identifiers to agent records 
- Adding new note fields to existing records 
- Creating and linking Bound-with Host records in Alma 
- Populating records with data from external sources 

To ensure projects are completed as efficiently and accurately as possible, please provide as much detail as you can when submitting a request. 

Incomplete or unclear requests may require follow-up questions and can delay project timelines. 

## Before Submitting a Request 

Consider the following questions: 
- What records or fields should be created or enhanced? 
- How can the affected records be identified? 
- How many records are estimated to be affected? 
- What new data should be added? 
- Where will the new data come from? 
- Are there records that should be excluded? 
-  Are there existing datasets, spreadsheets, or documentation available?  
- Do you have examples of the desired result? Providing examples is often the fastest way to help us understand your request. 

## Helpful Examples 

**Instead of:**
> We need new note fields added to records. 

**Consider:**
> Add a Conditions Governing Access note to all collection records in the Music Library Repository. The note text should be populated from the attached spreadsheet using the collection identifier as the matching field. Records that already contain a Conditions Governing Access note should not be modified. Examples of collections that should receive the note are 13456, 13789, and 134980. 

## What Happens Next 

After reviewing your request, we may: 
- Clarify project requirements 
- Review sample records and source data 
- Identify affected records 
- Confirm creation or enhancement rules 
- Discuss data sources and matching criteria
